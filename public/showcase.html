PM & Engineering Interview Guide

Talking points & technical architectural rationale

1. Problem Statement & Business Context

Wholesale food distributors face high stockout penalties (often 5-15% of order value) when customer sales orders cannot be fulfilled from local warehouse stock. Historically, buyers spend 2-4 hours daily manually calling suppliers or checking separate portals.

2. Core Operational ROI
  • Automated Real-Time Shortage Resolution: Shortage detection triggers integrated API queries to active vendors, allowing 30-second PO dispatch directly from the Sales Order screen.
  • AI Vocabulary Vector Field Binding: Reduces new supplier onboarding time from 3 weeks of manual engineering script writing to 5 minutes of automated schema discovery.
  • Financial Compliance Thresholds: Enforces supervisor approval rules on dispatches exceeding $5,000 to prevent runaway procurement.
3. Technical Architecture & Reliability
Architecture: React + TypeScript + Express API Proxy
Auth Support: OAuth 2.0 (Token Refresh), X-API-KEY, Basic
Mapping Algorithm: Vector Similarity on JSON payload keys
Error Fallback: Graceful circuit breaker on API 401/500
4. UX & Visual Design System

Designed with dense, high-contrast, professional enterprise aesthetics (slate-950 headers, indigo primary accents, emerald/rose status badges). Zero fluff or promotional noise — every pixel is tailored for high-frequency ERP power users.
